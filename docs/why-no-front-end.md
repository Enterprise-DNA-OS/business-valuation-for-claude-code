# A valuation desk without an application screen

The operator asks for overdue evidence, changes a scenario or drafts the weekly review. The agent runs the same CLI every time; the database stores the answer and the history. Read-only HTML views show the week and the method comparison. Documents use brand.json for the business name, logo and colours.

A screen adds mobile forms, spreadsheet editing, shared cursors, drag-and-drop documents and offline capture. This base has none of those. It is useful for a trusted adviser working at a computer with entered records. Enterprise DNA can scope a web interface and licensed data connections for a custom version. Database role configuration and authentication remain deployment work.

There is no need for a front end to perform the five weekly rituals: scope review, earnings adjustments, scenario review, evidence follow-up and the Monday pack. Generated documents are drafts. The professional conclusion stays with the practitioner.
